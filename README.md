 Zillow Scraper & Form Bot
Scrapes rental listings from a Zillow clone and auto-submits each property — address, price, and URL — into a Google Form.
Built with Python · Requests · BeautifulSoup · Selenium

⚙️ Setup
bashgit clone https://github.com/HusseinAshraf10/zillow-scraper-form-bot.git
pip install -r requirements.txt
python main.py
